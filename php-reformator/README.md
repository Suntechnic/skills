# Переформатирование php-файла

Приводит указанный php-файл к соглашениям проекта: префиксы локальных переменных, `{` на строке условия, альтернативный синтаксис в блоках с HTML, guard-clause без скобок, `declare(strict_types=1)` и PHPDoc с входящими переменными. Правит файл на месте, поэтому запускайте в git-репозитории и проверяйте результат через `git diff`. Сообщает только об ошибках.

```
Загрузи skill php-reformator и переформатируй файл <путь>.
```
