# Создание общего плана

Запускается один раз в начале задачи, когда в папке ещё нет overview.md и log.md. Скилл исследует код и создаёт overview.md: цель, критерии завершения, границы, рабочие блоки, стратегию проверок и риски. Затем создаёт log.md с записью OVERVIEW_CREATED. Если при исследовании возникли блокирующие вопросы, скилл задаёт их, а не сохраняет предположения. Следующий шаг — tosir-plannextstage.

```
Загрузи skill tosir-overview.
Папка задачи: <путь>
Задача: <описание>
```
