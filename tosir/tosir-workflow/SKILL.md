# Профиль запуска автоматизированного цикла выполнения задач tosir

## Процесс

Используй регламент навыка tosir.
Порядок операций, состояние и условия остановки определяй только по нему.
Запуск полного цикла по этому навыку разрешает:
- оркестратору — последовательные переходы по регламенту;
- reviewer (или выбранному вместо него агенту ревью) — коммитить принятые этапы.

## Контекст

Не читай реализацию и полные планы вместо субагентов.
Для управления циклом используй регламент, log.md и краткие отчёты.
Другие артефакты читай точечно, если без этого нельзя проверить результат операции или определить следующий шаг.

Перед каждым запуском проверяй разрешённость операции и актуальность плана по log.md с учётом CORRECTION и USER_DECISION. Передавай исполнителю tosir-implementstage полный пакет запуска по tosir:
- абсолютные пути к папке задачи, текущему плану и рабочим репозиториям;
- основной этап stage-NN и режим: первый запуск, доработка или продолжение;
- для доработки или продолжения — base и branch каждого репозитория из первой IMPL_STARTED этапа с учётом CORRECTION, краткое описание текущих изменений этапа;
- ограничения и относящиеся к операции решения пользователя, включая согласованные изменения исходных критериев приёмки.

Не передавай весь журнал, историю сессий или содержимое планов: исполнитель читает только текущее задание. Если обязательные параметры нельзя однозначно получить из журнала и доступных сведений, остановись и запроси уточнение; не выдумывай их.

После завершения операции перечитай новые записи log.md и проверь ожидаемый переход. Если ожидаемой записи нет или результат противоречив, остановись. Не переходи дальше только на основании отчёта субагента.

## Исполнители

Для каждой операции выбирай первого доступного агента из её строки таблицы, слева направо. Все перечисленные варианты заранее разрешены.

| Операция | Агенты |
|---|---|
| tosir-overview | planner, architect |
| tosir-plannextstage | planner, architect |
| tosir-implementstage | builder, maker, implementer, developer |
| tosir-reviewstage | reviewer, checker, tester |
| tosir-review | reviewer, checker, tester |

Каждому исполнителю поручай загрузить указанный навык и выполнить одну операцию.

Для доработки передавай исполнителю только путь к текущему самодостаточному stage-NN-M.md, не поручай читать исходный план и предыдущие доработки. Это ограничение не относится к ревьюеру: он читает исходный контракт этапа и текущий план доработки по tosir-reviewstage.

При вызове tosir-reviewstage явно передавай разрешение на коммит принятого этапа, предоставленное запуском этого workflow.
Если коммит не выполнен, останови цикл независимо от REVIEW_ACCEPTED.

Каждую операцию запускай в новой дочерней сессии.
Не выполняй операции параллельно.

Если необходимый навык недоступен или недоступны все агенты из строки операции — остановись.
Не используй агентов вне списка без разрешения.
