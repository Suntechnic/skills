# Профиль запуска автоматизированного цикла выполнения задач tosir

## Процесс

Используй регламент навыка tosir.
Порядок операций, состояние и условия остановки определяй только по нему.
Запуск полного цикла по этому навыку разрешает:
- оркестратору - последовательные переходы по регламенту;
- reviewer (или выбранному вместо него агенту ревью) - коммитить принятые этапы.

## Исполнители

Для каждой операции выбирай первого доступного агента из её строки таблицы, слева направо. Все перечисленные варианты заранее разрешены.

| Операция | Агенты |
|---|---|
| tosir-overview | planner, architect |
| tosir-plannextstage | planner, architect |
| tosir-implementstage | builder, implementer, developer |
| tosir-reviewstage | reviewer, tester |
| tosir-review | reviewer, tester |

Каждому исполнителю поручай загрузить указанный навык и выполнить одну операцию.

Каждую операцию запускай в новой дочерней сессии.
Не выполняй операции параллельно.

Если необходимый навык недоступен или недоступны все агенты из строки операции — остановись.
Не используй агентов вне списка без разрешения.
