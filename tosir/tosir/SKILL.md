# Выполнение задачи согласно плана, в несколько этапов

Этот skill описывает регламент, а не запускает автоматическое выполнение всей задачи.

Загрузка tosir не является командой загрузить или выполнить все перечисленные навыки.

За один запуск выполняй только операцию, явно запрошенную пользователем, если не указано обратное.
После её завершения остановись.

Не выбирай другую модель и не переходи к следующей операции самостоятельно, если на это нет явного разрешения.

## Входные данные

Определи из запроса и контекста папку выполняемой задачи;
Папка может содержать следующие файлы:
- overview.md - общий план задачи.
- stage-NN.md - план очередного этапа задачи пригодный для передачи исполнителю.
- stage-NN-N.md - план дороботок этапа, если результат этапа не был принят агентом выполняющим ревью.
- log.md - отметки агентов о выполненнении своих итераций
- другие файлы относящиеся к задаче

## Выполнение задачи

Выполнение задачи начинается с однократного запуска скила tosir-overview, результатом которого является создание файла overview.md в папке задачи.
Далее последовательно выполняются скилы:
- tosir-plannextstage - результа появления очередного stage-NN.md, например stage-01.md
- tosir-implementstage - работа агента по выполнению этапа stage-NN.md
- tosir-reviewstage - проверка агентом результата выполнения tosir-implementstage, в случае если результат не принят, агент может создать файл доработок stage-NN-N.md
  - Если результат принят - переходим к началу данной последовтаельности
  - Если результа не принят и создан stage-NN-N.md - выполняем tosir-implementstage над планом stage-NN-N.md

Каждый агент, начиная работу, просматривает необхдимый ему этап и файл log.md. 

Каждый агент, завершив работу, заносит ее результат одной строкой в файл log.md. Например:
- Составлен план очередного этапа и сохранен в файл stage-01.md
- Выполнены работы согласно плана этапа stage-01.md
- Работы по этапу stage-01.md приняты, этап можно считать завершенным
- Работы по этапу stage-01-1.md нельзя принять, этап не считается завершенным, подготовлен план доработок stage-01-2.md
- и т.п.

Планы описывают согласованные задания и не являются источником текущего статуса.

Актуальное состояние определяется по log.md.
Если записи неоднозначны или противоречат друг другу,
остановись и запроси уточнение.
