# Запуск реализации этапа плана

Запускается, когда последняя запись log.md — STAGE_PLANNED, REVIEW_REWORK или USER_DECISION с next=tosir-implementstage. План (stage-NN.md или доработку stage-NN-M.md) скилл берёт из log.md, указывать его не нужно. При первом запуске основного этапа рабочее дерево должно быть чистым: результат предыдущего этапа должен быть закоммичен. Иначе скилл остановится и сообщит об этом. Скилл записывает base, выполняет план и проверки, в конце пишет IMPL_DONE или IMPL_STOPPED. Commit, push и deploy без отдельного разрешения не выполняет.

```
Загрузи skill tosir-implementstage и выполни очередной этап по плану.
Папка задачи: <путь>
```
