# Запуск реализации этапа плана

Запускается, когда последняя запись log.md — STAGE_PLANNED, REVIEW_REWORK или USER_DECISION с next=tosir-implementstage. План берётся из log.md. При первом запуске этапа рабочее дерево должно быть чистым: предыдущий принятый этап закоммичен, иначе скилл остановится. Результат — IMPL_DONE или IMPL_STOPPED в log.md. Commit, push и deploy без отдельного разрешения не выполняются.

```
Загрузи skill tosir-implementstage и выполни очередной этап по плану.
Папка задачи: <путь>
```
